# ERP Sales Dashboard

Interactive ERP Sales Analytics Dashboard built using HTML, CSS, JavaScript, and Chart.js.

## Features
- Executive KPI dashboard
- Revenue trend analysis
- Salesperson performance tracking
- Quarterly and monthly insights
- Interactive charts and filters
- ERP-style analytics UI

## Tech Stack
- HTML
- CSS
- JavaScript
- Chart.js
